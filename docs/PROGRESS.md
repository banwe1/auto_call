## 五、下一步：验证 dev-b33（导入向导 + 辅助功能）

**导入向导**
1. 拨号页底部「导入号码」→ 首页显示 `解析到0个号码` + 四个入口 + `下一步`
2. 手写输入：空白时显示灰色说明，输入多行号码 → `导入` → 回首页显示 `解析到N个号码`；再点文件导入可继续累加
3. 首页按返回 → `退出导入流程确认`（取消留下 / 确认清空退出）
4. `下一步` → 号码归属：新任务时光标自动在标题框且弹出输入法；切「历史任务」→ `请选择 ⌄` → 白卡弹窗列出任务名 + 时间
5. `下一步` → 去重三开关（默认全关）→ `下一步` → 汇总页显示 `本集合去重：跳过` 等 + `筛除X个，剩余Y个`
6. `导入结束` → 返回拨号主页，新任务出现且号码在「未拨打」里
7. 打开某任务 → 添加号码后再试「数据库去重」应筛掉重复
8. 导入设置 → 解析号码类型：`仅限11位手机号` 时含固话的文本不应导入

**辅助功能**
9. 任务详情底部「辅助」→ 辅助功能页：默认 `自动开启扬声器` 开、`未接通自动挂断` 开且显示 `40秒`；`已接通自动挂断` 关（不显示秒数行、不显示两个访问行）
10. 打开 `已接通自动挂断` → 出现 `60秒` 行 + `接通时访问 / 挂断时访问`；点秒数弹出白卡弹窗（灰底输入框、取消白/确定蓝）
11. 拨一通（自动或手动）：接通后应自动开免提；`自动开启录音` 打开时，小米自带拨号器的录音按钮应被自动点击（其他 ROM 可能无该按钮）
12. 未接通自动挂断：把 `拨号后多少秒后挂断` 改成 10 秒，拨一个空号/关机号 → 10 秒后自动挂断
13. `通话状态同步 / 接通时访问 / 挂断时访问 / 手机兼容适配` 点击提示「暂未实现」

## 六、已知问题 / 风险

- **自动录音依赖系统拨号器**有「录音」按钮（小米/华为/OV 一般有；原生 Android 无 → 无效），失败只写日志不打扰
- **已接通自动挂断**从系统通话状态变为 offhook 开始计时（并非运营商侧真正接通的精确时刻）
- **导入不支持 xls/xlsx**（选中会提示另存为 txt/csv）；「下载模板」「电脑导入」为无响应占位
- 任务详情行内不显示「情况 / 是否接通」（以 base 截图为准）
- 运行页 `删除下一个` 同步批次 total；`多选删除号码` 仍不减 total（仅客户量同步）
- 手动拨号页「拨号卡」跟随全局设置，不单独持久化
- **Maven Central 会对共享 IP 返回 429 限流**（run 24）；已加 `gradle.properties` 重试配置
- **本机没有 Flutter/Dart SDK**：只能靠 CI 编译验证（约 8 分钟/次）
- CI artifact 下载需 GitHub token（本机 GCM 的 `gho_` 凭据可用；用 `curl -C -` 断点续传）
- 任务详情「导出」为占位按钮（点击无响应）
- 号码级状态存在 `Customer.note` 的 JSON 里（不改 Isar 结构），筛选在内存中完成
- 旧批次（dev-b18 之前导入）的号码没有拨号状态，会全部落在「未拨打」
- Isar 3.1 在部分 Android 15+（16KB page）设备有兼容风险
- 仍使用 debug 签名（侧载可用，不可上架）
